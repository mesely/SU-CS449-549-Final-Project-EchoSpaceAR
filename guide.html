4. Python backend nasıl başlatılır?

4.1. Terminal aç

  1. Mac’te Terminal aç.
  2. Şu klasöre git:
cd /Users/selmanyilmaz/SU-CS449-549-Final-Project-EchoSpaceAR/Python_Pipeline/server

4.2. Eğer bir sanal ortamın varsa onu aktifleştir

Repo içinde hazır bir .venv görünmüyor. Yani burada doğru komut: önceden hangi Python ortamıyla bu backend’i çalıştırdıysan onu kullan.

Eğer ilk çalıştırmada ModuleNotFoundError alırsan, bu projede şu paketler özellikle gereklidir: sounddevice, tensorflow, tensorflow_hub, faster_whisper, google-genai.

İlk kurulum için şu komut güvenli başlangıçtır:

python3 -m pip install numpy matplotlib scipy joblib scikit-learn sounddevice tensorflow tensorflow-hub faster-whisper google-genai

Eğer sounddevice sonrasında PortAudio benzeri bir hata verirse, macOS'ta ayrıca şunu da kur: 

brew install portaudio

Doğrudan sistem Python ile denemek istersen:

python3 -m current_pipeline.a_pipeline
Bu makinede gördüğüm gerçek hata

Bu rehber yazıldıktan sonra komut test edildi ve ilk düşen hata ModuleNotFoundError: No module named 'sounddevice' oldu. Yani komut formatı doğru, ama Python ortamında bağımlılıklar eksik.

4.3. Beklemen gereken çıktı

  • Terminalde HTTP server at http://0.0.0.0:8000 benzeri bir satır görünmeli.
  • Bir matplotlib penceresi açılmalı.
  • Bu pencere kapanırsa backend de durur. Test boyunca açık bırak.

6. SampleScene içinde neyi nerede kontrol edeceğim?

Hierarchy’de aşağıdaki ana objeleri görmelisin:

BackendSystem → BackendHttpClient + AudioCaptureController
UIController → BackendEventRouter
IconManager → label → sprite eşlemesi
Canvas → StatusText, SubtitleText, SummaryText, Yamneticon
MicPermission → Android/Quest mikrofon izni

6.1. BackendSystem objesine tıkla

  1. Hierarchy panelinde BackendSystem objesini seç.
  2. Inspector panelinde iki script görmelisin: BackendHttpClient ve AudioCaptureController.
Component Alan Ne yapacaksın?
BackendHttpClient Base Url Editor testi için http://127.0.0.1:8000, Quest testi için http://<MAC_IP>:8000 yaz.
BackendHttpClient Client Hello Path /client_hello olarak bırak.
BackendHttpClient Audio Chunk Path /audio_chunk olarak bırak.
BackendHttpClient Events Path /events olarak bırak.
BackendHttpClient Poll Interval Seconds 0.1 veya 0.5 olabilir. Sahnedeki mevcut değer 0.1.
AudioCaptureController Target Sample Rate 16000 bırak.
AudioCaptureController Chunk Duration Seconds Mevcut sahnede 0.1. Şimdilik değiştirme.
AudioCaptureController Preferred Device Keyword Harici Rode gibi bir cihaz kullanıyorsan Wireless mantıklı. Quest dahili mikrofonu kullanacaksan boş bırakman daha güvenli olabilir.
AudioCaptureController Pan Mover Yamneticon objesindeki YamnetIconPanMover2 referansı gelmeli.
Sahnedeki en kritik ayar

Şu an SampleScene içinde kayıtlı URL http://172.20.10.10:8000. Bu adres Mac’inin şu anki ağ IP’si değilse BackendSystem > BackendHttpClient > Base Url alanını mutlaka güncelle.

  3. Aşağıdaki referanslar dolu olmalı:

6.3. IconManager objesine tıkla

  1. Hierarchy içinde IconManager objesini seç.
  2. Inspector içinde IconManager component’ini aç.

Şunları kontrol et:

  • Icon Image → Yamneticon objesinin Image component’i
  • Label Sprites → speech, sirens, dog, music, door_knock, explosion_gunshot, cat, glass_break gibi eşlemeler dolu
Küçük ama önemli bir UI notu

Mevcut sahnede IconManager.labelText alanı StatusText objesine bağlı. Bu yüzden ikon label’ı geldiğinde status satırını ezebilir. Daha temiz bir HUD istiyorsan Label Text alanını boş bırak ya da ayrı bir TMP obje bağla.

6.4. Canvas objesine tıkla

  1. Hierarchy içinde Canvas objesini seç.
  2. Inspector içinde şu ayarları görmelisin:
  • Render Mode → World Space
  • Event Camera → XR/Main Camera
  • Scale → yaklaşık 0.002
  • Local Position → kamera önünde, yaklaşık z = 1.5

7. Unity Editor içinde hızlı smoke test nasıl yapılır?

Bu test, önce ağ ve UI kablolamasının doğru olduğunu anlamak için iyi bir adımdır. Quest build almadan önce bunu yapmanı öneririm.

  1. Önce Python backend’i başlat ve açık bırak.
  2. Unity’de BackendSystem seç.
  3. Base Url alanını http://127.0.0.1:8000 yap.
  4. Scene kaydet.
  5. Unity üst bar’dan Play butonuna bas.
  6. Console’u aç: Window > General > Console.
  7. Şunları bekle:
  • [BackendHttpClient] client_hello OK benzeri log
  • AudioChunk sent logları
  • Status text ya da ikonun güncellenmesi
Editor testinde başarılıysan

HTTP köprüsü, JSON formatı, event polling ve UI routing büyük olasılıkla doğru çalışıyor demektir. Sonraki adım Quest build almak olur.

8. Quest üzerinde nasıl çalıştıracağım?

8.1. Quest’i hazırla

  1. Quest cihazını Developer Mode ile aç.
  2. USB kablo ile Mac’e bağla.
  3. Headset içinde çıkan Allow USB debugging sorusunu onayla.
  4. Quest ve Mac aynı Wi‑Fi ağına bağlı olsun.

8.2. Base URL’yi değiştir

  1. Unity’de BackendSystem objesine tıkla.
  2. BackendHttpClient > Base Url alanına http://<MAC_IP>:8000 yaz.

Örnek: http://192.168.1.36:8000

8.3. Android build al

  1. Unity menüsünde File > Build Profiles aç. Bazı layout’larda bunun adı Build Settings görünebilir.
  2. Platform olarak Android seç.
  3. Gerekirse Switch Platform tıkla.
  4. Sahneler listesinde Assets/Scenes/SampleScene.unity işaretli kalsın.
  5. Build And Run tıkla.
  6. İstersen çıktı klasörü olarak repo içinde Builds/Quest adında bir klasör seç.

8.4. Headset üzerinde beklenen davranış

  • Uygulama açılır.
  • Mikrofon izni istenirse onay ver.
  • Python terminalinde audio_chunk ve event logları akmaya başlar.
  • Unity tarafında ikon, text ve gerekirse özet alanları güncellenir.

9. Sahneyi sıfırdan kurmak istersen

Mevcut SampleScene üzerinden gitmek daha kolaydır. Ama bir şeyler bozulursa sahneyi elle tekrar kurman için minimum iskelet aşağıdaki gibidir.

9.1. Backend objesi oluştur

  1. Hierarchy içinde sağ tıkla.
  2. Create Empty seç.
  3. Adını BackendSystem yap.
  4. Inspector’da Add Component tıkla.
  5. BackendHttpClient ekle.
  6. Tekrar Add Component tıkla.
  7. AudioCaptureController ekle.

9.2. UI controller objesi oluştur

  1. Yine Create Empty ile yeni obje oluştur.
  2. Adını UIController yap.
  3. BackendEventRouter component’ini ekle.

9.3. Icon manager objesi oluştur

  1. Yeni bir empty obje oluştur.
  2. Adını IconManager yap.
  3. IconManager component’ini ekle.

9.4. Kamera altına world-space Canvas kur

  1. Hierarchy içinde kamera objesini bul.
  2. Kamera üstünde sağ tıkla > UI > Canvas.
  3. Canvas seçiliyken Inspector’dan:
    • Render Mode → World Space
    • Event Camera → kamera objesi
    • Position Z → yaklaşık 1.5
    • Scale → yaklaşık 0.002

9.5. Canvas altına dört UI elemanı ekle

  1. StatusText → TextMeshPro UGUI

10. Hangi Python script’i hangi C# tarafına denk geliyor?

C# Script Rolü Python tarafı

AudioCaptureController.cs FMOD ile ses yakalama ve chunk gönderme a_pipeline.py içindeki feed_unity_chunk()

  • c_audio_core.py → ses işleme, YAMNet, stereo özet

  • e_transcription.py → faster-whisper STT
  • f_llm.py → Gemini özetleme

11. Sorun giderme

Unity bağlanmıyor

  • Python terminalinde gerçekten HTTP server at http://0.0.0.0:8000 çıktı mı?
  • Doğru proje açık mı? Quest2_3 olmalı.
  • Base Url doğru IP’yi mi gösteriyor?
  • Quest ve Mac aynı ağda mı?
  • Mac firewall Python bağlantısını engelliyor olabilir.

Editor’de çalışıyor ama Quest’te çalışmıyor

  • Editor testinde 127.0.0.1 kullanıp Quest testinde değiştirmeyi unutmuş olabilirsin.
  • Quest cihazı localhost ile Mac’e ulaşamaz.
  • USB debugging onayı reddedilmiş olabilir.

İkon değişmiyor

  • BackendEventRouter > Yamnet Icon Display boş olabilir.
  • IconManager > Icon Image yanlış objeye bakıyor olabilir.
  • O label için sprite eşlemesi yoksa defaultSprite görünür ya da hiçbir şey görünmez.

LLM özet gelmiyor

  • API anahtarı yoksa LLM otomatik dry_run moduna geçer.
  • Temel YAMNet ve STT akışı bundan bağımsız test edilebilir.

python3 -m current_pipeline.a_pipeline hiç başlamıyor

  • Bu durumda önce bağımlılık kurulum komutunu çalıştır.
  • Bu makinede eksik görülen paketler: sounddevice, tensorflow, tensorflow_hub, faster_whisper, google-genai.
  • Komutun kendisi yanlış değil; genelde sorun Python environment tarafında olur.

Mikrofon hiç çalışmıyor

  • Quest içinde mikrofon izni verilmiş mi?
  • MicPermission objesi sahnede aktif mi?
  • AudioCaptureController > Preferred Device Keyword çok dar olabilir. Gerekirse boş bırak.
  • FMOD cihaz seçimi için Unity Console loglarına bak.
Canlı bridge ile benchmark kabul mantığı aynı şey değil

Şu an Unity canlı akışı current_pipeline/a_pipeline.py üzerinden dönüyor. Benchmark tarafında konuştuğumuz yeni karar mantığı ise ayrı bir runtime hattında yaşıyor. Yani Quest demo akışını bugün çalıştırmak için bu rehber doğru, ama benchmark’ta kabul edilen en yeni mantığı birebir Unity’ye taşımak istersen ayrıca entegrasyon yapılması gerekir.
